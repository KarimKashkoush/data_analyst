# تشخيص مهارات القدرات — مدارس المعالي الإبداعية

[افتح الداشبورد](https://karimkashkoush.github.io/data_analyst/)

لوحة عربية تفاعلية بهوية مدارس المعالي الإبداعية، لعرض اختبار أولي مدرسي مقترح لـ150 طالبًا و10 مهارات لفظية وكمية.

تشمل نظرة عامة، وترتيب المهارات المحتاجة للتدريب، وقوائم الطلاب المحتاجين للدعم، وتشخيص كل طالب، وخريطة المهارات، وسيناريوهات التحسن والمتابعة.

**البيانات والأسماء اصطناعية للتدريب والعرض، وليست سجلات فعلية للمدرسة. سيناريوهات التحسن افتراضات تخطيط وليست تنبؤات مؤكدة.**

الموقع يعمل من ملف `index.html` دون خادم أو خدمات خارجية. بيانات النسخة المنشورة ثابتة ولا تتحدث تلقائيًا عند تعديل ملف Excel.

## تحديث الموقع

استبدل `index.html` بنسخة الداشبورد الجديدة ثم ارفع التغيير إلى الفرع المنشور. تتولى GitHub Pages نشر التحديث.
